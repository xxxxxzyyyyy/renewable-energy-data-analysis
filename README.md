
# 中国省级可再生能源月度数据分析

## 1. 项目简介

本项目使用 Python 对2019—2025年六个省区的光伏、风电和水电月度数据进行清洗、探索性分析和可视化。

本项目使用教学用途的合成数据，主要用于练习完整的数据分析流程，不代表真实官方统计结果。

## 2. 项目目标

- 识别并处理原始数据中的质量问题
- 分析三类可再生能源的发展趋势
- 比较不同省份的能源结构
- 分析能源发展的季节性
- 探索资源条件、装机容量和发电表现之间的关系
- 输出清洗数据、分析表格和图表

## 3. 使用技术

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
